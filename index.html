About the question bank

Version 2026.11.2 — 1020 hard questions across all four SC-500 exam domains. The bank lives in per-topic files under data/topics/ (23 topics), listed in data/bank.json, and is the only source of truth for both modes, so Learn and Evaluate can never drift apart.

  • Never delete: a question that becomes outdated is marked deprecated or superseded, kept in the bank and in git history, and replaced by a new versioned question. Corrections bump the version and are recorded in CHANGELOG.md.
  • Versioned: every question has a stable ID (for example D1-CA-001), a version, a status, a topic, a difficulty, and a source link. Bank releases are tagged, for example bank-2026.11.2.
  • Sources: Microsoft Learn and Azure official publications only — the official SC-500 study guide and SC-500T00 (12 learning paths, 63 modules), plus Azure docs where Learn has no page. Every question cites its source page with a link and a short quoted rule. Full list: data/SOURCES.md (131 pages).
  • Original practice only: these are original exam-style practice questions. They are not real exam questions and not exam dumps.
  • Quarterly updates: the bank is re-checked against Microsoft Learn every quarter (January / April / July / October). New and corrected questions are added as new versions; nothing is removed.
  • Privacy: no login, no tracking, no server. Your Learn progress and exam history are stored only in your browser (localStorage) and never leave your device.

Exam facts: the real SC-500 is 120 minutes, pass mark 700. The simulator shows a percentage and a pass / fail at 70% as a proxy for 700 — it is not a real Microsoft scaled score.
